# Internal GInteractions setters

Internal GInteractions setters

## Usage

``` r
set_seqnames1(x, value)

set_seqnames2(x, value)

set_start1(x, value)

set_start2(x, value)

set_end1(x, value)

set_end2(x, value)

set_width1(x, value)

set_width2(x, value)

set_strand1(x, value)

set_strand2(x, value)

# S4 method for class 'GInteractions'
first(x) <- value

# S4 method for class 'GInteractions'
second(x) <- value

# S4 method for class 'GInteractions,factor'
set_seqnames1(x, value)

# S4 method for class 'GInteractions,factor'
set_seqnames2(x, value)

# S4 method for class 'GInteractions,numeric'
set_start1(x, value)

# S4 method for class 'GInteractions,numeric'
set_start2(x, value)

# S4 method for class 'GInteractions,numeric'
set_end1(x, value)

# S4 method for class 'GInteractions,numeric'
set_end2(x, value)

# S4 method for class 'GInteractions,numeric'
set_width1(x, value)

# S4 method for class 'GInteractions,numeric'
set_width2(x, value)

# S4 method for class 'AnchoredPinnedGInteractions,numeric'
set_width1(x, value)

# S4 method for class 'AnchoredPinnedGInteractions,numeric'
set_width2(x, value)

# S4 method for class 'GInteractions,character'
set_strand1(x, value)

# S4 method for class 'GInteractions,character'
set_strand2(x, value)
```

## Arguments

- x:

  a GInteractions object

- value:

  a value passed to the corresponding field

## Value

A modified GInteractions
